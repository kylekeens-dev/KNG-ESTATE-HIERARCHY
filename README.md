# KNG Estate Organisation Chart

A red-and-black organisation chart with public read-only viewing and password-protected admin editing. The starter chart is based on the structure in the supplied reference image.

## Run locally

1. Install Node.js 18 or newer.
2. In this folder run `npm install`.
3. Set two environment variables:
   - `ADMIN_PASSWORD` — your private admin password.
   - `SESSION_SECRET` — a long random secret used to sign the admin login cookie.
4. Run `npm start` and open `http://localhost:3000`.

PowerShell example (use your own values):

```powershell
$env:ADMIN_PASSWORD="choose-a-long-private-password"
$env:SESSION_SECRET="paste-a-long-random-secret-here"
npm install
npm start
```

## Deploy on Render

1. Create a GitHub repository and upload the contents of this folder.
2. In Render, choose **New + → Blueprint** and connect the repository. Render reads `render.yaml`.
3. When prompted, set `ADMIN_PASSWORD` to a strong password only you know. `SESSION_SECRET` is generated by the Blueprint.
4. Deploy. The included persistent disk stores chart changes between deploys.
5. Visit the Render URL and use **Admin login** to edit the chart.

The chart is public to view. Only someone with the admin password can add, edit or delete positions. Do not put the password in frontend files or commit it to GitHub.

## Editing the chart

- Use **Add position** to create a new role.
- Use **Edit** on a card to change its title, name or reporting line.
- Use **Add below** to create a direct report under a role.
- Deleting a role moves its direct reports up to that role's manager, rather than deleting the whole branch.

The initial chart is stored in `server.js` as the starter structure and is copied to the persistent data file on first run.
